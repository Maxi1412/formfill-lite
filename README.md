# FormFill Lite

A simple browser-based PDF form filler for fixed-layout documents.

## What it does
- Opens a PDF locally in the browser.
- Keeps the original PDF layout fixed.
- Adds text, checkmarks, and X marks on top.
- Lets you move or delete only your additions.
- Includes font-size controls, zoom, page navigation, undo, and redo.
- Downloads a new completed PDF.
- Does not upload the PDF to FormFill Lite.

## Use
Open the GitHub Pages site, choose **Open PDF**, add the required information, then choose **Download PDF**.

## Privacy
PDF file content is processed in your browser. FormFill Lite has no upload server or account system.

## Libraries
- Mozilla PDF.js 3.11.174
- pdf-lib 1.17.1
